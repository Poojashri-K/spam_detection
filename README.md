# ML-Based Scam Message Detection & Threat Severity Analysis System

## 1. Project Overview

This college project analyzes SMS and other message text. A machine learning model classifies each message as **Spam** or **Ham**, while a separate rule-based analyzer assigns a threat severity level of **Low**, **Medium**, or **High** and returns reasons for detected warning signs.

The project uses the **UCI SMS Spam Collection** dataset. This dataset contains messages labeled as spam or ham; it is used here as a proxy for scam-like message detection and is not a dedicated dataset of verified scams.

## 2. Features

- Analyze a message through a React interface and Flask API
- Extract text features with TF-IDF
- Train and compare Logistic Regression, Multinomial Naive Bayes, and SVM models
- Report model performance and confusion matrices
- Return a confidence score for the SVM prediction
- Provide rule-based threat severity analysis
- Return reasons and detected text indicators to help explain the analysis

## 3. System Architecture

```text
React Frontend
    → Flask Backend
    → Text Preprocessing
    → TF-IDF
    → ML Model
    → Prediction
    → Severity / Explanation
    → React UI
```

The React frontend sends a message to the Flask API. The backend cleans and vectorizes the text with the saved TF-IDF vectorizer, passes it to the saved SVM model, and combines the prediction with rule-based severity and explanation results. The UI displays the analysis and the saved model evaluation metrics.

## 5. Dataset

- **Dataset:** UCI SMS Spam Collection
- **Messages used by this project:** 5,572
- **Labels:** Ham and Spam

The dataset is a spam/ham corpus. In this project it serves as a proxy for scam-like message detection, so its predictions should be interpreted in that context.

## 6. Machine Learning Models

- **Logistic Regression:** A linear classifier that estimates the relationship between message features and the spam/ham labels.
- **Multinomial Naive Bayes:** A probabilistic classifier commonly used with word-count or text-vector features.
- **Support Vector Machine (SVM):** A classifier that finds a separating boundary between the classes. The application uses the trained linear SVM for message predictions and confidence estimates.

The training script evaluates all three models on the same stratified train/test split. The saved SVM and TF-IDF vectorizer are used by the prediction API.

## 7. Evaluation Metrics

- **Accuracy:** The fraction of all predictions that are correct.
- **Precision:** Of the messages predicted as spam, the fraction that are actually spam.
- **Recall:** Of the actual spam messages, the fraction correctly identified.
- **F1-score:** The harmonic mean of precision and recall.
- **Confusion Matrix:** Counts correct and incorrect predictions by class: true negatives (TN), false positives (FP), false negatives (FN), and true positives (TP).

The training script saves comparison metrics and confusion matrices to `backend/models/model_metrics.json`, which the frontend retrieves through the metrics API.

## 8. Threat Severity

Threat severity is determined with rules, not machine learning. The analyzer looks for indicators such as suspicious URLs, urgent language, requests for passwords or OTPs, financial terms, prize claims, and account or security warnings. It combines detected indicators to assign **Low**, **Medium**, or **High** severity and returns matching reasons.

## 10. Setup and Installation

The commands below use PowerShell on Windows. Run backend commands from `D:\ML\backend` and frontend commands from `D:\ML\frontend`.

### Backend

```powershell
cd D:\ML\backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Place the UCI SMS Spam Collection file at `backend/data/SMSSpamCollection`. Then generate the model artifacts and metrics:

```powershell
python train_model.py
```

Start the Flask API:

```powershell
python app.py
```

The API runs on `http://127.0.0.1:5000`.

### Frontend

Open another PowerShell window:

```powershell
cd D:\ML\frontend
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## 11. Important Note

The ML model predicts **Spam** or **Ham** based on the labels and examples available in the UCI SMS Spam Collection dataset. Since that dataset is a spam/ham dataset used as a proxy for scam-like messages, the result is not a guaranteed real-world scam detector. Predictions, confidence scores, and rule-based severity indicators are informational and may be incorrect.
